# Tugas-1-proses-dan-simulasi-digital
Pilih satu sistem nyata yang menggunakan proses akuisisi dan/atau pengolahan sinyal digital. Contoh:
1. Sensor IoT (suhu, kelembapan, tekanan, cahaya, getaran).
2. Sistem audio atau mikrofon digital.
3. Kamera digital/CCTV.
4. ECG atau sistem biomedis.
5. Sistem monitoring lingkungan.
6. Sensor getaran mesin.
7. Sistem komunikasi atau instrumentasi digital.
   
Studi kasus antar mahasiswa sebaiknya berbeda agar analisis lebih beragam.
